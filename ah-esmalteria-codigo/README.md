# Ah! Esmalteria — versão online

Abra COMEÇAR-AQUI.md para criar o projeto Supabase, configurar o aplicativo e liberar o acesso da manicure.

React Native + Expo. Login por e-mail e senha, perfil de cliente, reserva e cancelamento online. A cliente vê as próprias reservas; a manicure autorizada vê a agenda completa. Horários ocupados são compartilhados sem dados pessoais. O servidor valida preços, duração, datas e conflitos simultâneos.

Valores: mão R$28; pé R$35; pé e mão R$55; escalda-pés R$10; francesinha R$3; adesivo (par) R$3. Duração de 30/30/60 minutos para os serviços principais e sem tempo extra nos adicionais. Domingo e segunda fechados. Expediente inicial de terça a sábado, 9h às 18h.

Identidade visual baseada na logo fornecida. Interface com Início, Agenda, Serviços e Meu cadastro. Dados antigos locais não são migrados automaticamente.

Sem configuração online, o app mostra uma tela de preparação e não confirma reservas. Código fonte, sem APK. Sintaxe validada; integração com projeto real e testes em dispositivo pendentes.
